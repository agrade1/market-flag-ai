# Market Inference — 하이브리드 추론·데이터 추출 방법론

Market Flag AI는 "완벽한 미시 데이터 없이도 논리적 추정치를 제공"하는 서비스다. 이 스킬은 그 추론 품질과 정확도를 보장하기 위한 규칙이다.

## 1. 데이터 우선순위 (실데이터 우선, 추론은 최후)

추정값을 만들 때 항상 이 순서로 근거를 쌓는다. 윗단계가 가능하면 아랫단계로 내려가지 않는다.

1. **실측 공공데이터** — 통계청/KOSIS, 공공데이터포털, 업종별 거시 지표(인구, 가구, 사업체 수, 소비지출 등)
2. **검색 트렌드 비율** — 네이버 데이터랩/구글 트렌드. 절대값이 아닌 **상대 비율·증감 추세**로만 사용(트렌드는 규모가 아니라 관심도/모멘텀의 프록시).
3. **유사/상위 시장에서의 비례 추정** — 직접 데이터가 없으면 상위 카테고리 데이터에 트렌드 비율을 곱해 분해(top-down).
4. **LLM 통계 추론** — 위 어떤 것도 없을 때만. 명시적 가정 위에서 추정하고 반드시 "추정"으로 표시.

핵심: **트렌드 데이터는 시장 규모를 직접 의미하지 않는다.** 규모는 거시 데이터에서, 관심도/경쟁 모멘텀은 트렌드에서 가져와 결합한다.

## 2. TAM / SAM / SOM 추정 규칙

- **TAM (전체)**: top-down(거시 데이터 × 카테고리 침투율) 또는 bottom-up(잠재 고객 수 × ARPU) 중 가능한 방식. 두 방식이 모두 가능하면 교차검증.
- **SAM (접근 가능)**: TAM에 지역·채널·세그먼트 필터를 적용. 적용한 필터를 명시.
- **SOM (현실적 확보)**: SAM에 초기 창업자 기준 점유율 가정(보통 한 자릿수 %)을 적용. 점유율 근거(경쟁 강도·진입장벽)를 명시.
- 모든 추정치는 **단일 숫자가 아니라 범위(보수/기본/낙관)** 와 **단위·기준연도·통화**를 함께 제시. 거짓 정밀도(예: 1,234,567,890원) 금지 — 유효숫자 2~3자리로 반올림.
- 각 단계에 **사용한 가정·수식·출처**를 구조화해 응답에 담는다(`assumptions`, `formula`, `sources`).

## 3. 레드/블루오션 판정

복수 신호를 0~100 점수로 정규화해 합성한다(단일 지표 의존 금지):
- 검색 관심도 추세(성장/정체/하락)
- 경쟁 강도(사업체 수·광고 경쟁·기존 플레이어 밀도 프록시)
- 시장 성장성(거시 지표 CAGR)
- 진입장벽(규제·자본·기술)

점수 → 라벨(레드/중립/블루)과 함께 **근거 신호별 기여도**를 같이 반환한다.

## 4. 타겟 페르소나 도출

- 성별·연령 분포는 공공 인구통계 + 카테고리 소비 통계 + 트렌드의 인구통계 분해를 결합. 가능하면 분포(%)로.
- 페르소나는 분포에서 도출하되 "문제 상황·소비 동기"는 추론으로 보완하고 추론임을 표시.

## 5. 정확도·신뢰도 원칙 (가장 중요)

- 모든 응답에 **데이터 충분도(confidence)** 를 단계로 표기: `high`(주로 실데이터) / `medium`(트렌드 보정) / `low`(주로 추론).
- `low`/`medium`이면 화면·응답에 **"데이터 부족으로 인한 AI 추정 리포트"** 임을 명시(`ui-guideline`의 AssumptionNotice 연계).
- **출처 추적**: 각 수치에 출처/방법(measured | trend-adjusted | inferred)을 태깅.
- **새너티 체크**: SOM ≤ SAM ≤ TAM, 비율 0~100%, 인구 분포 합 ≈ 100% 등 경계 검증. 위반 시 보정·재추정.
- **환각 방지**: 존재하지 않는 통계·수치를 지어내지 않는다. 모르면 추정임을 밝히고 가정만 제시.
- 외부 API 실패/누락은 에러가 아니라 **fallback(추론 경로)** 로 처리하고 confidence를 낮춘다.

## 6. 구현 매핑

- 데이터 수집: `src/lib/data-sources/*`(public-data, trend-data, mock-market-data) — 각 소스는 실패 시 null/부분데이터를 반환하고 호출부가 fallback 결정.
- 추론·프롬프트: `src/lib/ai/market-diagnosis-prompt.ts`(가정·출처 태깅을 강제하는 지시 포함), `market-diagnosis-service.ts`.
- 응답 스키마: `src/lib/ai/report-schema.ts` — `confidence`, `sources`, `assumptions`, 범위값 필드를 스키마에 명시하고 LLM 출력을 검증(zod 권장).
- LLM 호출은 `api-builder` 에이전트 규칙(키 보안·모듈 분리)을 따른다. Claude 사용 시 `claude-api` 스킬로 모델/파라미터 확인.

## 체크리스트 (추론 코드/프롬프트 작성 시)
- [ ] 거시 데이터 → 트렌드 보정 → 추론 순서를 지켰나
- [ ] 모든 수치에 출처/방법·가정·범위·단위가 붙는가
- [ ] confidence가 산출되고 부족 시 안내 문구가 노출되는가
- [ ] 새너티 체크(SOM≤SAM≤TAM 등)를 통과하는가
- [ ] 외부 API 실패 시 fallback으로 죽지 않는가
